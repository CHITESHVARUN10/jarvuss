🚀 1. PHASE 1 — MVP FEATURES
🎯 Goal:

A fully offline voice assistant for macOS that listens for “Jarvis” and executes basic commands.

✅ Features in Phase 1
🎙️ Voice System
Continuous microphone listening
Wake word detection: "Jarvis"
After wake word → record command
🗣️ Speech Processing
Convert speech → text (offline)
Handle basic noise
🧠 Command Engine
Parse commands like:
“open chrome”
“close vscode”
“create file test.txt”
“open folder downloads”
💻 System Actions
Open applications
Close applications
Create files/folders
🤖 AI Integration (Ollama)
For queries like:
“Jarvis, explain recursion”
Send to local LLM → get response
📜 Logging (optional but recommended)
Store:
commands
timestamps
🧰 2. TECH STACK (FINAL DECISION)

👉 Use Swift + Native macOS APIs (NOT Flutter)

🧠 Core Stack
Component	Tech
Language	Swift
UI (optional)	SwiftUI
Audio	AVFoundation
Wake Word	Porcupine (Picovoice)
Speech-to-Text	Whisper.cpp
AI	Ollama
System Commands	AppleScript + Shell
Database	SQLite
📦 3. REQUIREMENTS (DEPENDENCIES)

This is your real “requirements.txt equivalent”

🔹 A. System Requirements

Install:

# Homebrew (if not installed)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install cmake
brew install ffmpeg
brew install portaudio
🔹 B. Ollama
brew install ollama

Run:

ollama run llama3
🔹 C. Whisper.cpp (Speech-to-Text)
git clone https://github.com/ggerganov/whisper.cpp
cd whisper.cpp
make

Download model:

./models/download-ggml-model.sh base.en
🔹 D. Porcupine (Wake Word)

Download from:
👉 https://picovoice.ai/

Get:
Porcupine SDK (macOS)
"Jarvis" keyword file
🔹 E. Swift Packages (SPM)

In Xcode, add:

.package(url: "https://github.com/ggerganov/whisper.cpp", from: "1.0.0")

(Or call via CLI instead of embedding)
